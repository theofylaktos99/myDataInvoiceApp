## 🚀 Quick Start Guide

### 💻 Development Setup

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production  
npm run build

# 4. Preview production build
npm run preview
```

### 🌐 Deployment

```bash
# Deploy to Vercel
npx vercel login
npx vercel --prod
```

### 📱 Usage

1. **Access the app** at the live URL
2. **Manage company settings** in the top-right menu
3. **Add customers** via the sidebar navigation
4. **Create invoices** using the main form
5. **Preview & export** PDF documents
6. **Send to myDATA** (mock integration)

### 🏗️ Architecture Highlights

- **Component-Based Design:** Modular, maintainable React components
- **State Management:** Efficient useState hooks with useMemo optimization
- **Local Storage:** Browser-based persistence for offline capability
- **Responsive Design:** Mobile-first, Tailwind CSS implementation
- **Type Safety:** TypeScript integration for better code quality

### ⚡ Performance Features

- **Fast Build Times:** Vite's optimized build pipeline (~2.5s)
- **Small Bundle Size:** 66.36 kB gzipped total payload
